### Управление внутри контейнера
Внутри контейнера работают команды для управления ocserv:
occtl - управление ocserv
ocpasswd - менеджер паролей

``` Пример
docker exec -it $(docker ps -q --filter=name=ocserv | head -n1) occtl reload
```

### iphone и большие диапазоны сетей
iOS-клиент AnyConnect имеет практические ограничения на число одновременно применяемых маршрутов/профилей туннелирования, и известны случаи, когда сложные списки split-routes ломают подключение или работу интернета именно на iOS, тогда как на Android/Windows/Linux то же самое работает
Для решения этой проблемы можно создать конфиг для группы 0000, задать для нее полный роут (0.0.0.0/0), отредактировать `config/ocserv/ocpasswd` заменив пользователям группу на `0000` (вторая колонка, разделитель знак ":")

``` config/ocserv/config-per-group/0000
dns = 14.16.0.1
route = default
```
``` config/ocserv/ocpasswd
guest01:0000:$5$xW73BYNYZh
```

### ocserv.conf
Настройки очень хорошо документированы в сети. При необходимости, ИИ очень хорошо справляется с разъяснениями их
#### Подстройка MTU
Осуществляется под каждого клиента, происходит разовый рекконект
`try-mtu-discovery = true`

#### Проверка свободного IP
Не тратим немного времени, на проверку "а не занят-ли адрес, который мы выдали клиенту"
`ping-leases = false`

#### Изоляция клиентов между собой
`isolate-workers = true`

#### Управление группами
параметры routes, no-routes, dns, nbns из группового конфига полностью перезаписывают глобальные значения
`config-per-group = /etc/ocserv/config-per-group/`
